# outring-cc

Claude Code plugin marketplace.

```
/plugin marketplace add outring/cc
/plugin install subagent-cost-guard@outring-cc
```

| Plugin | Description |
|---|---|
| [subagent-cost-guard](plugins/subagent-cost-guard/README.md) | Blocks subagent dispatches that would silently inherit an `opus` or `fable` model until they name a tier |
